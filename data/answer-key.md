# Pilot answer key: five Q3 2026 earnings calls

Written on October 20, 2026, from the full transcripts, before any summary was generated. Ten facts per call that an investor would need. Do not change this key after seeing the summaries; if a fact turns out to be badly chosen, note it in the write-up instead.

**Columns.** *Where*: PR = prepared remarks, QA = analyst Q&A (where the fact is first or only stated). *Neg*: Y if the fact is bad news, a risk, or a caveat that cuts against the headline. *Caveat to keep*: the qualifier a summary must carry for the fact to count as fully kept.

**Scoring each fact in each summary.** Kept (gist and key number or direction right) / Dropped / Wrong (number or direction wrong) / Caveat lost (stated, but without the qualifier in the last column). Also count, per summary, any claim that is not in the transcript at all (unsupported).
